# Virtual Production: Future of Film Scenography?
### Reveal.js Presentation (English B1, ~5 Minutes)

A clean, authentic minimalist presentation designed for easy manual tweaking and deployment to GitHub Pages. It follows a Swiss/Helvetica black-and-white minimalist aesthetic (pure white background, bold typography, simple hyphens, zero decorative frames, cards, or drop-shadows).

---

## 🚀 How to Run Locally

### Option 1: Direct in Browser
Simply double-click [index.html](index.html) to open it in Safari, Chrome, or Firefox.

### Option 2: Local HTTP Server (Recommended)
From this directory, run:
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

---

## 🌐 How to Deploy to Free GitHub Pages

This presentation is 100% self-contained with relative paths, optimized media, and zero build step required.

1. Create a new repository on GitHub (e.g. `virtual-production-presentation`).
2. Initialize and push this folder:
   ```bash
   git init
   git add .
   git commit -m "Minimalist Reveal.js presentation"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. Go to **Settings** &rarr; **Pages** in your GitHub repository.
4. Under **Branch**, select `main` and root `/`, then click **Save**.
5. Your presentation will be live at `https://<your-username>.github.io/<repo-name>/`!
